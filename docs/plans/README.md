# Plans

Temporary plans for features that span several modules. One file per feature: `docs/plans/<topic>.md`.

1. Write the plan before implementing: goal, approach, affected modules, test strategy, open questions.
2. Get it agreed with the maintainer.
3. After implementation, **delete the plan**. Move decisions that stay relevant into an ADR in
   [docs/adr/](../adr/) first.

This directory should be empty on `main` most of the time.
